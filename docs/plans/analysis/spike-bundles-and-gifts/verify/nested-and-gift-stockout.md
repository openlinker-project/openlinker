# Verify: nested bundles and gift stock-out across competitors

Accessed 2026-11-04. Read-only check of two claims from primary sources (vendor help, API docs, vendor-run app pages). Every quote below was re-read on the page during this check; where the live page blocked, a Wayback raw snapshot (`id_`) was used and its timestamp is given.

## Verdicts

| Claim | Verdict |
|---|---|
| 1. "Every competitor forbids nested bundles" | **False.** Cin7 Core documents three-level assemblies. Brightpearl contradicts itself. BaseLinker and Apilo are unknown: the BaseLinker quote used earlier is about a different feature. Forbidden: Linnworks and Shopify. Sellasist forbids one direction. |
| 2. "No competitor has a policy for a free gift that runs out" | **False as worded.** Brightpearl waits, Shopify shows the gift as sold out and the offer stops, IdoSell only adds a gift that has stock, Sellasist blocks by default with an override, and a Shoper app keeps a stock buffer. **What holds:** no competitor substitutes another gift or notifies the buyer. |

## Claim 1 - nested bundles

| Competitor | Nested bundle | Evidence |
|---|---|---|
| BaseLinker | **Unknown** | The help page on bundles ("Jak tworzyć zestawy produktów?", https://base.com/pl-PL/pomoc/wiedza/zestawy/) and the product-relationships page (https://base.com/en-EN/help/knowledgebase/product-relationships/) say nothing about it. The quote used in r1/r2/r5, "relationships between two bundles are not allowed", is real but sits under the **`relations`** field of `addInventoryProduct` (https://api.baselinker.com/index.php?method=addInventoryProduct). That field covers manual related, substitution, up-sell, down-sell and cross-sell links. Bundle composition is set by the separate `bundle_products` field. Full sentence: "relations array A complete list of up to 1000 manually defined product relationships. ... Parent-variant relationships and bundle-composition links cannot be duplicated manually, and relationships between two bundles are not allowed." It forbids a cross-sell link between two bundles, not a bundle inside a bundle. |
| Apilo | **Unknown** | The help page "Zestaw produktów - do czego służy i jak utworzyć" (https://apilo.com/pl/help/zestaw-produktow-do-czego-sluzy-i-jak-utworzyc/) says nothing about a set inside a set. The only constraint it states: "jeśli w Towary i usługi > Produkty nie znajdują się pojedyncze pozycje magazynowe mające wchodzić w skład zestawu, musisz dodać nowe produkty". |
| Sellasist | **Forbidden (one direction documented)** | https://sellasist.pl/pomoc/ (post 4676, "Informacje o zestawach w karcie produktu"): "Jeżeli spróbujesz przekształcić produkt będący już częścią zestawu, pojawi się komunikat o błędzie: „Nie możesz utworzyć zestawu z tego produktu, ponieważ jest częścią składową zestawu. ... Jeżeli chcesz utworzyć zestaw z tego produktu, skopiuj go i powtórz czynność.”" This blocks turning a component into a set. Whether an existing set can be added as a component of another set is not stated. |
| Linnworks | **Forbidden** | https://help.linnworks.com/support/solutions/articles/7000044542 : "Linnworks only supports one-layered compositions." / "A Parent item can have child items, but those child items cannot have their child item." / "Our system is not designed to support such setup." |
| Shopify Bundles (help + API) | **Forbidden** | Help, "Eligibility and considerations" (https://help.shopify.com/en/manual/products/bundles/eligibility-and-considerations): "Bundles can't contain other bundles." Dev docs (https://shopify.dev/docs/apps/build/product-merchandising/bundles/add-variant-fixed-bundle): "Nested bundles aren't supported. A bundle can't have components and be part of another bundle simultaneously." API enum `ProductVariantRelationshipBulkUpdateUserErrorCode` (latest): "NESTED_PARENT_PRODUCT_VARIANT - Nested parent product variants aren't supported." The API refuses it, so a bundle component cannot be a bundle. |
| Cin7 Core | **Allowed** | "Multi-level Assembly" (https://help.core.cin7.com/hc/en-us/articles/9034476129295; live page 403, Wayback snapshot 2025-10-16 06:55:14): "Cin7 Core supports multi-level assemblies." The worked example is three levels deep: "Level 3: Back to School Kit Uniform x 1 (Level 1) Sport Kit x 1 (Level 2) Level 2: Sport Kit Protective Gear x 1 (Level 1) ...". It also defines how picking behaves: "If auto-assembly is enabled only on Sport Kit ... The system will pick only pre-assembled units of Protective Gear ... If there are no pre-assembled units of Protective Gear in stock, the auto-assembly will not complete." |
| Brightpearl | **Contradictory: help forbids, API models it** | Help, "Shopify products" (help.brightpearl.com/hc/en-us/articles/360020598831; Wayback 2023-01-28, article "Updated December 06, 2022"): "Note: Brightpearl only allows a single level of bundles and does not support any nested bundles (a bundle within a bundle)." API, Product Bundle GET (https://api-docs.brightpearl.com/product/product-bundle/get.html): "returns a list of the bundles that contain a given product, and recursively any bundles that contain those bundles" with the example "It is a component of two bundles, 303 and 391, and bundle 391 is itself a component of bundle 488." API, Order Row DELETE (https://api-docs.brightpearl.com/order/order-row/delete.html): "If the order row is a bundle parent, the child components will all be deleted as well. This includes children-of-children in nested bundles." The help note sits in the Shopify article, so the limit may apply to the Shopify connector only. The data model and order rows support nesting. |

## Surprises

1. **The BaseLinker "no nesting" quote cited in r1, r2 and r5 C-039 is misattributed.** It belongs to the `relations` field (cross-sell and similar links), not to `bundle_products`. BaseLinker nesting is unknown, not forbidden.
2. **Cin7 Core is the counter-example to claim 1.** It documents multi-level assemblies and states what picking does when a sub-assembly has no pre-built stock.
3. **Brightpearl contradicts itself.** The help says one level. Two API pages (bundle tree, order-row delete "children-of-children in nested bundles") assume nesting. The help note may cover the Shopify connector only.
4. **Claim 2 should be narrowed to "no one substitutes or tells the buyer".** Four approaches exist:
   - stop the offer: Shopify, IdoSell, Apilo's set approach;
   - block the action: Sellasist;
   - wait silently: Brightpearl, which does not even set an error status;
   - add regardless: Linnworks.

   Only a third-party Shoper app keeps a stock buffer and an operator error queue.
5. **IdoSell and Shopify both forbid the reverse combination.** IdoSell: "Towar Gratisowy nie może być zestawem". Shopify: a bundle is limited by its scarcest component, so a sold-out gift inside a bundle stops the bundle.
