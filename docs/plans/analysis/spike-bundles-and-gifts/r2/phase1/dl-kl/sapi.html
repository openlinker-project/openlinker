This page allows you to execute API requests directly. Just fill in your Client Key and Secret Key in the fields at the top of the page and click Explore. Then you can expand any of the endpoint descriptions, fill in the fields, and click the "Try it out!" button. This will perform an API request to the server and display the results in the page. Please read the documentation before you start.

Warning: When you click the "Try it out!" button, the page will query and alter live product data on the Kaufland marketplace. If you delete a unit on this page, that product will no longer be offered in your shop, effective immediately! Be very careful when exploring endpoints that alter data.
For testing and exploring API endpoints in a safe environment, visit the Seller API Playground. For detailed documentation about how to use the playground, visit the Playground Documentation.
