Shopify: Rules & Guidelines 

This page will explain some rules and concepts relevant to working with Shopify through Linnworks.

Inventory updates

Enable inventory tracking

Shopify's inventory policy needs to be set to Shopify tracks this product's quantity in the Inventory policy list. It is required to automatically reflect changes made to items when you sell or receive new stock. Follow this guide to see how to enable inventory tracking.

SKU codes

When creating new products, Shopify allows you to use the same SKU code across multiple products. However, there is no way for Linnworks to safely understand which item should be linked to a Linnworks inventory item. Therefore, you must always have unique SKUs within a single Shopify account. If you do not ensure this, Linnworks will map to the first one found, which may not be correct.

Internally to Shopify, each item is listed as a unique identifier known as product_id or variant_id. These identifiers are auto-generated by Shopify when a new item is added to the catalog. Linnworks records these ids during the mapping process for use by the system when updating inventory levels or prices. This is required when updating this data to Shopify through the API. If an item that has already been mapped in Linnworks is removed and subsequently recreated on Shopify, the link in Linnworks becomes broken as Shopify created a new Id when the item was recreated for the same SKU. In this situation, the item must be unlinked and relinked via the mapping screen.

Order dispatch

Digital items on orders

When processing orders that contain digital items, dispatch errors may be logged because the individual items have previously been marked as dispatched directly on Shopify before the order download. This does not affect the dispatch process or the uploading of tracking information.

Using different services

If you wish to use different shipping services for items within a single order, the order must be split, and the appropriate service must be selected for each order. When the order is processed, Linnworks will mark items as partially shipped on Shopify, along with the relevant courier and tracking information.

Carrier Name

Linnworks uses Shopify's automated tracking number system and, where possible, will attempt to match the carrier name to those predefined by Shopify. Shopify will use internal logic to assign another vendor if no match is found.  For more details, check our solution article.

Partially refunded orders

Orders that are partially refunded will be parked with a note suggesting you may need to remove refunded items by splitting the order. To learn how to split orders, see this guide. 

Order download

Orders with items in different locations on Shopify

On Shopify, an order can include items from different locations. When you download such an order in Linnworks, it will automatically split the order into separate orders according to the mapped locations for order downloading. 

This order split happens before any rules or packaging calculations occur. This ensures the correct calculations are applied to each item in the resulting orders. 

Note: Linnworks Shopify channel integration only downloads orders created within the last 3 months. Any orders older than this, even if modified in your Shopify account, will be ignored. This helps prevent issues with Shopify unexpectedly modifying orders. 

Digital Items

Shopify supports the concept of a digital item, a product that does not exist in the real world and can not be picked from your warehouse. These items should be automatically marked as dispatched on Shopify.

An example would be a pattern or written material emailed directly to your customer in PDF format. When an order contains a mixture of real and digital items, the digital one will be included when the order is downloaded. If Shopify does not supply an SKU code for the digital item, it will save it as a service item in the order. 

If a Shopify order contains only digital items, the whole order is marked as shipped and will not be downloaded to Linnworks.

Items without SKUs

If the ordered item has a Product ID but does not have an SKU, the order will be downloaded, and the SKU field on the order will be populated with the Product ID (Shopify_ProductId_xxxxxxxx_VariantId_xxxxxxxx). This ensures the ordered item is not incorrectly linked to existing  Linnworks SKUs.

No address supplied

When an order is downloaded from Shopify, and an address has not been provided, all address fields in Linnworks will contain UNKNOWN.

Product ID

If the ordered item does not have a Product ID on the Shopify backend, it will be saved as a service item in Linnworks.

Downloading What3Words data

What3Words has an official app available on Shopify for collecting and validating delivery addresses entered by buyers via this app.
