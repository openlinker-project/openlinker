 Channels Inventory Mapping | Linnworks Multichannel Guide 
 Inventory Mapping
 Inventory mapping is the process that links Linnworks stock items to a listing on a selling channel. This link allows information about the item to flow between Linnworks and the selling channels so that everything syncs according to the logic of  inventory updates . 
 Once linked, changes made to a stock item will reflect on all its linked listings, and orders for those listings downloaded into Linnworks can include stock item information.
 Using the Channel Mapping screen
 Go to Settings > Channel Integration and click the mapping    icon for the channel you want to manage.
  Once the screen opens:
 Clicking the    button at the top left-hand corner will allow you to customize what data the screen displays by adding and removing columns.
 The left-hand table contains a list of your active listings from the channel.
 The right-hand table lists your Linnworks stock items for manual mapping .
 A listing count and a count of linked & unlinked listings are at the bottom of the screen.
   Info:  The last synchronization time (Last Full Scan) is displayed in local time. 
 The settings menu
 Clicking on the cog    icon will open a menu with the following options:
 Link All By:
 SKU:  This automatically maps any listings in the grid to Linnworks stock items where the listing SKU matches the Linnworks SKU. 
 Choose channel inventory filters:
 All:  Display all channel listings whether they link to Linnworks inventory items or not. 
 Linked:  Only display channel listings that are linked to Linnworks inventory items. 
 Unlinked:  Only display channel listings that are NOT linked to Linnworks inventory items.
 Choose columns:  Ticking the options in the following menu will display or hide that column on the inventory mapping screen. 
Ignore: When ticked, Linnworks will ignore the listing when synchronizing inventory and will not send a revised stock level to the listing if the available quantity in Linnworks changes. This option is valid for all channels except for eBay. For eBay, Ignore Sync will apply to all listings with the same Channel SKU, not just a specific listing. Use the Strike Off functionality to break the connection between Linnworks inventory and a specific eBay listing.  
 SKU: This is the Stock Keeping Unit (SKU) identifier defined on the channel listing. 
 Channel Title: The channel listing title.
 FBA:  This indicator shows if the listing is a listing Fulfilled by Amazon. Because you cannot change the fulfillment status of a listing in Linnworks directly, this is just an indicator and not an on-screen control. By default, an FBA item is also marked as ignored. Note that this menu option is only available for Amazon channels. 
 Linnworks SKU: This is the SKU of the Linnworks inventory item mapped to the listing. 
 Linnworks Title: This is the title of the Linnworks inventory item mapped to the listing. 
 Max Listed:  If this value is greater than zero, then this is the highest quantity Linnworks will ever submit to the channel. More details on this feature can be found here . 
 End When:  If this value is greater than zero, then Linnworks will end the listing when the available drops to this value. More details on this feature can be found here . 
 Stock Percentage:  If this value is greater than zero, then Linnworks will submit the percentage of available stock to the channel. More details on this feature can be found here . 
 Last Update:  Available for Amazon. It shows when the last update was sent to the channel from Linnworks. 
 Mapped by:  Available for eBay. Shows which method was used to map SKU and listing. 
 Pending:  Available for eBay. Shows if a listing has Pending Relist status. 
 View logs: This option is only available for eBay channel integrations. It opens the eBay logs screen where you can strike off eBay listings or cancel the pending relist status of the listings. For full information, see the dedicated guide here .
 Mapping inventory
  Note:  Listings can only be mapped to Linnworks inventory if the listing has a  Channel SKU . Variation Parent SKUs and virtual/digital items will not appear on the mapping screen. 
 There are several ways for mapping inventory to channel listings depending on the setup of your listing SKUs and inventory in Linnworks.
 1. Link all by SKU
 This is the easiest and fastest way to use if the Channel SKUs match Linnworks SKUs. Click the    menu > Link all by > SKU, to link all items by SKU. Listings that have an existing matching Linnworks SKU display a yellow box in the rightmost column.  
 Once the linking job is complete, the Inventory Mapping screen will display a pop-up window displaying how many items were successfully linked. 
 Auto-link by SKU on channel level 
 You can configure each channel integration to automatically link your inventory items during order downloads or when the automatic mapping sync runs. This can be set up in two ways: 
 1. During initial integration (when first integrating a sales channel with Linnworks) 
 Every sales channel available for integration with Linnworks has a dedicated guide on completing the integration. The final step in the integration process for any channel is configuring additional settings, including the Auto-link by SKU setting. 
  Info:  For some channels, the Auto-link by SKU setting cannot be enabled during the initial integration. However, you can turn it on later from the channel’s configuration page, as explained below. 
 If enabled, when an order is downloaded into Linnworks and the channel SKU is not found, the system will attempt to match it with a Linnworks SKU. If a match is found, the channel SKU is automatically added to the corresponding Linnworks SKU (under Edit Product Details > Channel SKU ). Once the items are linked, the inventory sync is triggered. 
 With this setting enabled, the system also checks if items are correctly linked during the mapping sync , which runs approximately every 12 hours. At the end of the sync, Linnworks initiates the Auto-link by SKU feature, which is the same Link all by SKU feature from the Mapping screen but is enabled at the channel configuration level. This compares Linnworks SKUs to channel SKUs, and if a match is found, the system links them and triggers the inventory sync . 
 2. During configuration (at any time after integration) 
 If you would like to start using this feature for sales channels already integrated with Linnworks, you can enable it individually for each channel in the Edit Channel Details screen. To do that: 
Go to Settings > Channel Integration .
In the  Channel Integrations  screen, search for the required channel integration and click the  Edit  icon.
The Edit Channel screen will open. Scroll down to the Listings section and enable   Auto-link by SKU .
Save the changes.
 Now, the Auto-link by SKU feature will function during both order downloads and mapping syncs, as explained above.
 2. Manual mapping
 Manual mapping involves using the mapping screen to find both an individual listing and an appropriate Linnworks stock item, then manually clicking the link button to link them together.
 To manually map your listings.  
 Search for the listing you want to map using the search box at the top left.
 Select the listing by clicking on the row.
 Search for a Linnworks stock item using the search box at the top right.
 Click the    Link  button. 
 3. Creating Linnworks stock items from channel listings 
 If Linnworks does not find an SKU in inventory that matches the Channel SKU, it is possible to create a new stock item with a matching SKU from the mapping screen. This is indicated with the button   Create .
 To create a stock item from a channel listing:
 Click   Create 
 The Create new item  pop-up window will open and is pre-populated with data taken from the channel listing and can be customized whether required.
 Item Number:  Also known as SKU, is a unique identifier so that the item can be identified in Linnworks. 
 Item Title:  This is the title that will be given to the stock item in Linnworks.
 Quantity:  This is the current stock level at the location defined in the dropdown box.
 Location:  This drop-down menu will display all  locations  defined in Linnworks, including fulfillment centers. Select the one where you want to create your item.
 Once you are happy with the data, click    Save  to return to the Inventory Mapping screen or  Save & Edit , this will generate the stock item and then open the  Product Details  window where further details can be specified.
 4. Stock Item Linking Import
 Import is an alternative to Link All by SKU option as it allows to link many items in bulk. Additionally, the import allows linking Channel SKUs without matching Linnworks inventory items in bulk. 
 To run the import, create a CSV file with four columns specifying Channel SKU, Linnworks SKU, Source, and Subsource. For details and example files, check the Stock Item Linking Import guide.
 Unlinking inventory
 1. Removing Links manually
 Once a listing has been mapped to a stock item, it is possible to unlink them manually. 
 Search for the listing using the search box at the top left.
 Click the green    Unlink button.
  Note:  Unlinking a stock item from one eBay listing will also unlink any other eBay listings that share identical channel SKUs.For example, if an item is listed on both eBay UK and DE with the same channel SKU, removing the link between the stock item and the UK listing will also remove the connection between the stock item and the DE listing.
 2. Delete Stock Item Linking Import
 To remove inventory linking in bulk, use the Delete Stock Item Linking import. To run the import, create a CSV file with three columns specifying the Channel SKU to unlink, the Source, and Subsource. For details check the  Delete Stock Item Linking  guide.
 To unlink all items on the channel at once, download a list of all channel SKUs from Dashboards > Query Data  > Query Type: Channel SKUs . This report will display all Channel SKUs and their linked Linnworks SKUs.
 Refreshing the mapping screen
 When you make changes to your listings (e.g. updating the SKU or title) or create a new listing directly on the channel, it may take some time for the Channel Mapping screen to reflect these changes automatically.
 If you have made a significant amount of listing changes directly on the channel, you may want to request an update to the Mapping screen manually. This can be done for each channel individually in  Settings > Channel Integration > Edit Channel > Listings. 
 For eBay specifically,  Download listings  also triggers an inventory check. Linnworks will compare current stock levels in the system to the last sent data, and if there are any differences, new updates are sent to the channel. For this reason, a limit is added -  Download Listings for eBay can be clicked only once every 12 hours. 
 Download listings & Auto-link by SKU 
 If you download listings for your channels with the Auto-link by SKU setting enabled, it will update the Channel Mapping screen with missing listings (channel SKUs) and, in addition, automatically link matching channel SKUs to Linnworks SKUs. Once linked, the inventory sync will be triggered. See here for a detailed explanation of how the Auto-link by SKU feature works.  
 Special criteria
 In general, for all channels that support  Inventory Mapping , the feature works similarly. However, some channels require additional steps to be taken on the channel directly or have specifics that must be kept in mind while working with  Inventory Mapping  for the channel.
 Amazon Vendor
 In Amazon Vendor integration, two features are supported - Retail Procurement and Direct Fulfillment . However, both features cannot be mapped via the Channel Mapping screen since Amazon does not provide APIs for those features. The following guide details how to link inventory for Amazon Vendor integration.
 Kaufland
 Orders downloaded from Kaufland require an SKU for Linnworks to assign the order items correctly. Instead of SKUs, Kaufland uses two product identifiers. See here for full instructions on how to work with these identifiers.
 Magento 2
  Important:  Due to some API limitations on the Magento side, we recommend not to use forward slashes  (/) and percentage signs  (%) in your Channel SKUs on Magento 2. Magento 2 API cannot parse SKUs with / correctly, and stock level and price updates will fail. Please see here for further details.
 Magento 2 channel uses Reference IDs in addition to SKUs, allowing previously deleted SKUs to be recreated. To keep track of these cases and avoid duplicates, the Inventory Mapping for these channels has an additional field Reference ID,  and these references are checked in addition to SKUs during listing download.
 Additionally, items will not appear on the mapping screen if:
 The Product SKU of one item matches the Reference ID of another item.
 The item has a stock level of 0 on the Magento backend.
 For further details on the above matters, please see the Rules & Guidelines sections of Magento 2.
 Newegg
 Due to a limitation in the Newegg API, Linnworks cannot download the titles of the listings on Newegg. The SKU is downloaded and so as long as the SKU matches a Linnworks SKU, it can be mapped using Link all by .
 Wayfair  
 The I nventory Mapping screen is no longer supported for Wayfair due to API limitations. Inventory mapping for Wayfair must now be done using a data import . Please refer to the Stock Item Linking Import guide for instructions. 
 WooCommerce 
 WooCommerce offers a range of configurable options for products on WooCommerce directly. Not all the options are compatible with the Linnworks Inventory Mapping feature. Check here for the criteria both single items and variations must meet in order for the products to be available for linking in Linnworks.
