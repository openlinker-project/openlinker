 Icons and Symbols 
 Open Orders: Icons and Symbols
 There are a number of symbols and icons used in Open Orders to display the condition of the order visually: paid or unpaid, direct order, an order from a specific selling channel, locked order, parked order, etc. These make the order easy to spot on the screen, saving time to open orders individually to check them.
 Info! Depending on the type of view ( advanced or simple ) some icons and symbols may have different shapes. Instead of an icon, you may also see a text identifier in a simple view. The simple view type is still under development.

 Order tags 
 There is a number of order tags that you can apply to orders to mark and differentiate between them easily. These tags enable you to flag orders with your own rules. For example, a blue star may be the indicator of an order that needs to be processed urgently.  
 Note! Only a single tag can be assigned to an order.

 The Fulfillment column
 The fulfillment column shows if the order can be fulfilled using the available stock level in the location  where the order is saved. 
 See a  dedicated guide for more information on the fulfillment of open orders.
