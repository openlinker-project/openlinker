Allegropl linnworks integration user manual

eBusiness Guru > Allegropl linnworks integration user manual

Install application into linnworks.net

To use allegro.pl channel, you must first install it from within linnworks.net.

  • Login to linnworks.net
  • Check application store to install application. Screen will be display below:

  • Search Allegro.pl app and install it.

Integrate the channel into linnworks.net

  • Select settings in the left-hand menu bar
  • Select channel integration option

Integrate the channel into linnworks.net

  • Select the channel integration option. Screen will be display below:

By clicking on this button we can add new allegro.pl channel integration.

  • It return a list of available channel integration. Screen will be display below:

  • Locate allegro.pl on the list, and click on install application button.

By clicking on this button we can create allegro.pl channel integration. Screen will be display below:

  • Enter your allegro.pl account name to start the actual integration. And then click on next button for the next step.

  • After reading the disclaimer, please tick ‘I agree to the terms and conditions’ and next to continue integrating allegro.pl channel integration.

  • Select you marketplace to integrate channel and then click on next button for the next step.

Click on the “Generate Authorization Token” it will re direct to the your allegro login screen. Once you login to the account it will prompt for the grant the permission. Once you allow access. It will redirect to the following screen.

Then next button click to next screen will be display below.

Finish button click to all process complete in your channel integrated.

  • Allegro.pl channel integration process step all completed then finish button click to save all details.
  • To complete the integration, your allegro.pl integration should now show in linnworks.net channel integrations.

 

By clicking on this toggle button we can enable this channel and start to enable integration.

Edit channel configuration


By clicking on the Icon we can Edit channel for allegro.pl setting. Account, order, inventory, inventory price change, listings, API credentials.
